# Q6：舰种系数 K 的分解——伤害类型、集中度与增援

> **2026-08-30 全量重跑：** 限定 2025-01 之后的剧情回放（`start_dt >= 2025-01-01T00:00:00Z`），并修复两个数据问题：`damage_*_avia` 字段与 base 字段同值重复（航空伤害此前按两倍计入，已用官方总伤害对账验证），以及伤害类型按真实来源拆细。活动模式专属类型（激光/导弹/事件伤害）及水雷、波、深水炸弹在 2025+ 剧情回放中完全为零，实际出现 **11 种**伤害类型。有效回归样本 1943 局 / 13565 行（个人 455 局 / 3177 行，抓取 1488 局 / 10388 行）。

> **证据层级：** 伤害类型分析（三级探索性结论）、HHI 分析（三级探索性结论）、增援分析（二级结论）。

## 背景

Q6 试图回答：经验公式中的舰种系数 K（DD=0.83, SS=1.395, CV=0.75, 相对 CA=1.00）是 WG 的独立乘数，还是伤害类型/集中度等结构性差异的伪影？

社区提出四条假说：
1. DOT 被高估——DD 大量出伤来自点火/进水，DOT 可被大保健恢复，实际价值低于直伤，K_DD=0.83 只是在补偿
2. DD 伤害分散——DD 打多目标，每个目标份额小，不如 CA/BB 集中火力有效
3. 增援伤害无经验——不切断增援等于白打
4. 副炮伤害收益被削——副炮自动开火、无需玩家操作，社区长期传言其经验收益低于主炮

## 实验 A：分伤害类型

把 ship_eff 按伤害来源拆成 11 类（实际出现），重新拟合。单位 ship_eff 的经验系数（合并 1943 局全样本）：

| 航空鱼雷 vs 舰船鱼雷 | -0.0031 | -3.8 | <0.001 |
| 航空鱼雷 vs 俯冲航弹 | +0.0048 | +4.6 | <0.001 |
| 俯冲航弹 vs 主炮 | -0.0047 | -6.9 | <0.001 |

| 起火 vs 主炮 | -0.0004 | -0.6 | 0.52 |
| 进水 vs 主炮 | -0.0097 | -6.8 | <0.001 |
| 火箭 vs 俯冲航弹 | +0.0019 | +1.2 | 0.22 |
| 跳弹 vs 俯冲航弹 | +0.0017 | +0.8 | 0.43 |

**结论 1（假说①）：DOT 不能一体论，起火与进水要分开。** 起火系数 0.0134 与主炮 0.0137 无显著差异，进水系数 0.0041 显著偏低（约 -71%）。此前"DOT 被高估"的结论主要是进水拖累，起火本身并不打折。

**结论 2（假说④）：副炮收益确实低于主炮，折价约 20%。** 合并样本副炮 - 主炮 = -0.0027（HC0 t=-16.0）。折价温和，副炮仍高于俯冲航弹和进水。

**结论 3（航空鱼雷 vs 普通鱼雷）：不是一类。** 舰船鱼雷 0.0169 是全场最高，航空鱼雷 0.0138 显著低约 18%，但显著高于俯冲航弹 0.0091（高约 52%）。三类互不相同，此前把它们混入"鱼雷"或"航弹"桶都会扭曲系数。

**结论 4：俯冲航弹、火箭、跳弹可合并。** 三者系数 0.0091 / 0.0109 / 0.0108，火箭和跳弹与俯冲航弹的差异均不显著（p=0.22 / 0.43）。

**结论 5：防空/飞机伤害几乎不给经验。** 系数 0.0002（SE 0.0005），约为零。打飞机/防空伤害约占全部 ship_eff 的 2.1%，建议在后续模型中从 ship_eff 剔除。

拆分对比（合并口径）：baseline（单一 eff_total）R² = 0.8377，11 类拆分 R² = 0.8553（+0.0176）。

## 系数怎么生效：一个具体例子

系数是"每多 1 个船等价（ship-eff）伤害，玩家基础经验占队伍份额的增加量"。1 个船等价 = 对一艘敌舰造成相当于其满血的伤害，例如一艘 60,000 血的敌舰打满 60,000 伤害 = 1.0。

设一场 7v7 剧情，队伍基础经验池 `team_raw = 8,000`（本语料均值 7,770 / 中位数 8,658）。同一局内控制舰种、点亮和其他条件不变，只比较"多打出这 1 个船等价伤害"的经验收益：

| 伤害类型 | 系数 | 多 1 个船等价 → 经验增加 |
|----------|------|------------------------|
| 舰船鱼雷 | 0.0169 | +135 |
| 撞击 | 0.0144 | +115 |
| 航空鱼雷 | 0.0138 | +110 |
| 主炮 | 0.0137 | +110 |
| 起火 | 0.0134 | +107 |
| 副炮 | 0.0110 | +88 |
| 火箭弹 | 0.0109 | +87 |
| 跳弹 | 0.0108 | +86 |
| 俯冲/普通航弹 | 0.0091 | +73 |
| 进水 | 0.0041 | +33 |
| 防空/飞机伤害 | 0.0002 | +2 |

换算规则：`经验增加 = 系数 × team_raw`，与池子大小成正比（池子随星级/胜负浮动）。

单玩家例子：同一个玩家在一局里多打出 3 个船等价（相当于连续打穿 3 艘满血敌舰），其他条件不变。只看这 3 个船等价用什么伤害类型打出来：

| 伤害类型 | 3 个船等价的经验增加 |
|----------|--------------------|
| 全舰船鱼雷 | 3 × 135 = +405 |
| 全撞击 | 3 × 115 = +345 |
| 全航空鱼雷 | 3 × 110 = +330 |
| 全主炮 | 3 × 110 = +330 |
| 全起火 | 3 × 107 = +321 |
| 全副炮 | 3 × 88 = +264 |
| 全火箭弹 | 3 × 87 = +261 |
| 全跳弹 | 3 × 86 = +258 |
| 全俯冲/普通航弹 | 3 × 73 = +219 |
| 全进水 | 3 × 33 = +99 |
| 全防空/飞机伤害 | 3 × 2 = +6 |

同样的吃船量，只因为伤害类型不同，这个玩家最多可以差出约 306 经验（鱼雷 vs 进水，占 8,000 池子的约 3.8%）。

注意两点：
- 这是**边际效应**（局内去均值、控制舰种后的关联），"副炮低 20%"不是说副炮流 BB 整体亏 20%——舰种乘数已单独吸收，它描述的是同样多的伤害用不同武器打出来时的边际经验差。
- 经验池约一半是均分地板，剩余部分按贡献分配，所以边际收益本身已经包含了均分压缩；实际一局里击杀带来的星级/池子变化会叠加在这之上。

## 实验 B：分伤害集中度（HHI）

计算每个玩家对敌舰伤害的赫芬达尔指数（HHI）。

| 舰种 | 攻击目标数 | HHI | 最大目标占比 | 前三目标占比 | 平均 ship_eff |
|------|-----------|-----|-------------|-------------|--------------|
| DD   | 11.1 | **0.206** | 29.6% | 61.6% | 3.58 |
| CL/CA| 15.1 | 0.141 | 22.5% | 49.6% | 4.53 |
| BB   | 15.7 | 0.133 | 21.7% | 48.5% | 4.69 |
| CV   | 9.9  | 0.192 | 28.6% | 61.0% | 4.20 |
| SS   | 6.8  | **0.286** | 36.3% | 71.2% | 3.52 |

**结论：假说②被推翻，方向不变。** DD 的伤害比 CA/BB 更集中（HHI 0.206 vs 0.141/0.133），不是更分散。SS 仍是最集中的（0.286）。

回归中加入 HHI：

| 模型 | R² | K_DD | K_SS | K_CV | HHI 系数 |
|------|-----|------|------|------|----------|
| baseline | 0.8316 | -0.0076 | +0.0229 | -0.0376 | — |
| +HHI | 0.8731 | -0.0040 | +0.0327 | -0.0335 | -0.0886 |

> HHI 部分沿用 2026-08-27 语料（2068 局）的结果，未随 2025+ 重跑；与实验 A 存在小幅口径差。

HHI 有强烈的负效应（R² 从 0.8316 升到 0.8731）。加入 HHI 后，DD 的 class-specific residual coefficient 大幅下降（-0.0076 → -0.0040，约 47%）。SS 的 residual coefficient 被 HHI 掩盖（控制后 K_SS 从 +0.0229 升到 +0.0327）。

## 实验 C：增援伤害

四步检验，结论一致：**当前数据未发现增援伤害存在特殊的 0-XP 或显著折扣。**

- 跨 sec_failed 分组的玩家级回归：eff 系数平坦
- 控制 game_eff_per 后，sec_failed 系数为零，R² 不变
- 局级回归（含场景 FE）：sec_failed 主效应 ≈ 0，交互项为正
- 29 个场景逐一检验，sec_failed 系数无一致规律

**结论：假说③被推翻。** 切增援和杀增援对经验没有区别。详见 `docs/reinforcement-damage-analysis.md`。

## 综合结论

| 舰种 | K（vs CA） | 伤害类型 | 集中度 | 残余 class-specific multiplier |
|------|-----------|----------|--------|-------------------------------|
| DD   | 0.83 | 鱼雷 46.5% 高系数与主炮 43.9% 中系数大致抵消，无统一解释 | 解释约 47% | 剩余约 53% 待查 |
| SS   | 1.395 | 86% 舰船鱼雷（最高系数），解释约 30% | 掩盖（集中度惩罚拖累） | 控制后更大 |
| CV   | 0.75 | 74% 航空系（航弹/火箭低系数），解释约 62% | 几乎不解释 | 约一半是残余惩罚 |
| BB   | ≈1.00 | 副炮占 1/3、折价约 20%，但拆分后残余系数稳定 | 几乎不解释 | 稳定 |

**舰种系数 K = 伤害类型差异 + 伤害集中度惩罚 + 残余 class-specific multiplier，三重叠加。**
其中"残余 class-specific multiplier"包含未建模的舰种特征和可能的 WG 内部乘数，不应等同于已证明的 WG 固定变量。

## 重算 K：把伤害类型系数计入

把每个玩家的 ship_eff 按伤害类型系数折算成"主炮等价效率"（`eff_xp = Σ (b_c / b_main) × eff_c`），再用同一套等分地板 + 舰种乘数模型（`fit_class_efficiency.py`，a=0.50，lam=1.2）重新拟合舰种 K。

伤害类型权重（相对主炮 = 1.00）：鱼雷 1.23、撞击 1.05、航空鱼雷 1.01、起火 0.97、副炮 0.80、火箭 0.80、跳弹 0.78、俯冲航弹 0.66、进水 0.30、防空/飞机 0.01。

| 舰种 | K（原始 eff） | K（伤害类型加权） | 纯组成预期（相对 CA） |
|------|--------------|------------------|----------------------|
| DD   | 0.828 | 0.768 | 1.099 |
| CL/CA| 1.000 | 1.000 | 1.000 |
| BB   | 0.955 | 0.990 | 0.949 |
| CV   | 0.637 | 0.705 | 0.866 |
| SS   | 1.449 | 1.267 | 1.186 |

解读：
- **SS 的加成约 41% 是伤害类型组成**：SS 86% 是鱼雷（权重 1.23），把效率按类型计价后 K 从 1.449 降到 1.267，对 CA 的超额从 +0.45 缩到 +0.27；剩余约 0.27 才是真正要 WG 乘数解释的部分（叠加集中度惩罚后控制口径还会更大）。
- **CV 的惩罚约 19% 是组成**：CV 74% 是航空系低权重伤害，加权后 K 从 0.637 升到 0.705；对 CA 的缺口从 -0.36 缩到 -0.30。
- **BB 的惩罚基本是副炮折价**：BB 副炮占 33%（权重 0.80），加权后 K 从 0.955 升到 0.990，残余乘数接近 1.00。
- **DD 的 K 反而更低了**：DD 组成偏"值钱"（鱼雷 46% + 主炮 44%），按类型计价后效率上升，残余乘数从 0.828 降到 0.768——DD 的低 K 不是组成伪影，是真实的残余惩罚。
- 模型 R² 从 0.9131 升到 0.9182，说明按类型计价确实增加了解释力。

> 口径：原始 K 与本报告其余部分同源（2025+ 语料）；此前的发布值（CV 0.43 等）基于旧语料且未修 `_avia` 重复计数，CV 效率低估导致其 K 被低估。
