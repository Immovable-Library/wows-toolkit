# WOWS 回放归因引擎

把 WOWS 回放事件流重建为"为什么"，产出专业走位/瞄准建议；只报有证据支持的结论，测不了的项标"需事件级数据"。

## 术语

**单轮命中价值评估（single-shot hit value assessment）**:
对每一次命中/齐射，评估实际价值并给出弹药反事实建议（换弹种预期伤害差额、提前量、穿深判定），而非仅对比实际命中率与期望命中率。
_避免使用_: 实际命中率偏差、期望命中率对比（作为核心指标）

**落点簇几何**:
一次齐射多枚壳落点的统计特征：簇均值约等于瞄准点，围绕均值的离散约等于散布。用于把 H3（瞄准/提前量）与 H2（散布 RNG）分开——均值系统性偏移即为瞄准问题，均值压在目标上仅离散大即为散布运气。
_避免使用_: 命中率期望偏差（作为判别依据）

**弹药反事实（ammo counterfactual）**:
在同一局交战（同射程、同目标角度）下，把瞄准点换到该弹种**最优落点区**，估算改用另一弹种能拿到的伤害，并与实际结果对比。不是"瞄准点和提前量不变、单纯把这一轮 HE 换成 AP 看伤害变化"。每艘主炮仅两种弹种（HE+AP / HE+SAP / SAP+AP），故只对比**另一弹种**。AP 最优=主装/核心区是否可穿，HE 最优=上层建筑溅射+起火价值，SAP 最优=中层装甲穿透溅射价值。仅主炮，鱼雷不在范围。
_避免使用_: 同弹道换弹（瞄准点/提前量不变）

**瞄准 vs 穿深诊断（aim vs penetration）**:
对 AP 击穿少的归因拆分：落点在非击穿区（上层/炮塔面/艏艉/斜舷）=瞄错位置；落在主装且角度正常但碎弹（穿深<有效厚度）=穿深确实不够；落在主装却跳弹=目标角度问题。
_避免使用_: 单纯"命中率低"

**分区饱和（saturation）**:
船体按分区（艏/艉/上层/主装/核心）各有 `HitLocation.max_hp` 电量；分区累计伤害耗尽后该区饱和，后续非核心命中降到 ~1/6 伤害；核心命中永远 100%。
_避免使用_: "模块血量打空"（模块击破是失效，分区饱和才是减伤）

**主炮限定（main-battery only）**:
换弹反事实只针对主炮（玩家可手动选 AP/HE/SAP）；副炮/AA 自动炮命中排除。
_避免使用_: 对所有命中做换弹建议

**报告分档**:
普通报告=按目标教训；深度报告=逐轮全量（弹种/目标/命中数/勋带/部位/原因/评分）。
_避免使用_: 单一报告

**Sigma**:
炮的弹着聚集度按船常量（如斯大林格勒 2.65，全游唯一）。WG 官方 API 不提供；仅作为"散布是否反常"的置信度乘子，不当作硬依赖。
_避免使用_: 绝对期望命中率模型（作为核心）
