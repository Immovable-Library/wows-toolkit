# 一局剧情总共给多少经验（玩家版）

## 一句话

一局剧情总共给多少经验，主要看三样：哪张图、打了几颗星、赢没赢。跟你们打了多少伤害基本没关系。

## 三样决定因素

### 1. 哪张图（难度越高给越多）

下面是每一张剧情，在「打赢 + 5 星」这一口径下，整队（7 人）能分到的**基础经验池**。

| 剧情 | 分房 | 基础经验池 |
|---|---|---|
| 神盾 | 6-8 | 7477 |
| 杀人鲸 | 6-8 | 8352 |
| 营救猛禽 | 6-8 | 7915 |
| 防守纽波特 | 6-8 | 8048 |
| 那莱 | 6-8 | 8051 |
| 最终前线 | 6-8 | 8109 |
| 赫尔墨斯 | 6-8 | 7937 |
| 樱花绽放 | 6-8 | 7698 |
| 北极护航 | 6-7 / 7-9 / 9-11 | 暂无 / 8613 / 10059 |
| 东京快车 | 6-7 / 7-9 / 9-11 | 暂无 / 8761 / 9981 |
| 太平洋攻势 | 6-7 / 7-9 / 9-11 | 暂无 / 8867 / 9970 |

> 注：三张新剧情（北极护航 / 东京快车 / 太平洋攻势）都有**三档难度**，分房 6-7（低级）、7-9（中级）、9-11（高级），经验池按「6-7 / 7-9 / 9-11」排列；6-7 分房因为样本里没有「打赢 + 5 星」的对局，暂缺，可参照 7-9 档往下估。三档难度不只是分房不同，敌方阵容也会换：北极护航第一波低级是卡尔斯鲁厄、中级是纽伦堡、高级是希佩尔。

#### 三张新剧情的三档难度（第一波敌军）

| 剧情 | 6-7 低级 | 7-9 中级 | 9-11 高级 |
|---|---|---|---|
| 北极护航 | 卡尔斯鲁厄 | 纽伦堡 | 希佩尔 |
| 东京快车 | 若竹 / 睦月 | 峰风 / 吹雪 | 晓 / 白露 / 秋月 |
| 太平洋攻势 | 河内 / 石锤 | 金刚 / 扶桑 | 长门 / 纪伊 |

#### 老剧情的高等级变体

- 高级（8-11 分房）：约 9800
- 中级（7-9 分房）：约 8600
- 旗舰（9-10 分房）：约 1.2 万 - 1.4 万

### 2. 打了几颗星

每多一颗星，总经验多约 9%。从 0 星到 5 星，池子大概涨 3 倍多。

### 3. 赢没赢

赢了是输了的约 2 倍。

## 一个重要结论

队伍打多少伤害，基本不影响"总共给多少经验"。伤害只决定这 7 个人里谁分得多、谁分得少，不决定池子有多大。
