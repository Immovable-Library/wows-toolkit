# 一局剧情总共给多少经验（玩家版）

## 一句话

一局剧情总共给多少经验，主要看三样：哪张图、打了几颗星、赢没赢。跟你们打了多少伤害基本没关系。

## 三样决定因素

### 1. 哪张图（难度越高给越多）

下面是每一张剧情，在「打赢 + 5 星」这一口径下，整队（7 人）能分到的**基础经验池**。

|---|---|---|
| 神盾 | 6-8 | 7477 |
| 杀人鲸 | 6-8 | 8352 |
| 营救猛禽 | 6-8 | 7915 |
| 防守纽波特 | 6-8 | 8048 |
| 那莱 | 6-8 | 8051 |
| 最终前线 | 6-8 | 8109 |
| 赫尔墨斯 | 6-8 | 7937 |
| 樱花绽放 | 6-8 | 7698 |
| 北极护航 | 6-7 / 7-9 / 9-11 | 暂无 / 8613 / 10059 |

> 注：三张新剧情（北极护航 / 东京快车 / 太平洋攻势）都有**三档难度**，分房 6-7（低级）、7-9（中级）、9-11（高级），经验池按「6-7 / 7-9 / 9-11」排列；6-7 分房因为样本里没有「打赢 + 5 星」的对局，暂缺，可参照 7-9 档往下估。三档难度不只是分房不同，敌方阵容也会换：北极护航第一波低级是卡尔斯鲁厄、中级是纽伦堡、高级是希佩尔。

- 中级（7-9 分房）：约 8600
- 旗舰（9-10 分房）：约 1.2 万 - 1.4 万

### 2. 打了几颗星

每多一颗星，总经验多约 9%。从 0 星到 5 星，池子大概涨 3 倍多。

### 3. 赢没赢

赢了是输了的约 2 倍。

## 一个重要结论

队伍打多少伤害，基本不影响"总共给多少经验"。伤害只决定这 7 个人里谁分得多、谁分得少，不决定池子有多大。

## 挂机和暴毙是两回事吗

是两回事，但 replay 里看不到队友的"消极作战"判定标志，只能用行为近似区分：

- **挂机 / 逃兵**：一场下来伤害 0、击杀 0、点亮 0，而且早早就死了，经验几乎为 0。
- **暴毙**：开局没几分钟就死了，但死之前多少打过一点伤害或收过人头。

在我们这批 replay 里，真正的"零贡献"玩家非常少（2058 局只有 5 局），而且大多是只点亮的航母/潜艇或整队翻车的失败局，不是典型挂机。按这个近似算，零贡献玩家大约让全队经验池少 7.5%，暴毙大约少 3%。

所以玩家反馈的"挂机扣全队 1/7"（约 14%）在这批样本里没被证实，观测到的是更小的约 7.5%。这不代表机制一定不存在，而是我们抓的 replay 都是玩家主动上传的局，真正被判定消极作战的挂机局几乎不会出现在里面。要坐实 1/7，需要专门找带服务器挂机判定的样本。
