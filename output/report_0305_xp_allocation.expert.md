# 经验分配机制 + 舰种效率系数（机制 / 开发者版）

## 模型

对一局 n 名玩家：

```
contribution_i = ship_eff_i + lambda * (scouting_damage_i / 100000)

XP_share_i = a / n + (1 - a) * K[class_i] * contribution_i
                         / sum_j (K[class_j] * contribution_j)
```

- `ship_eff_i`：船等价击杀数 = 对每艘敌舰累加（你对它造成的伤害 / 它的最大血量）。
- `a`：均分地板比例（"任务池取平均"）。
- `lambda`：点亮伤害权重（每 10 万点亮伤害折算多少船等价）。
- `K[class]`：舰种效率系数。

## 拟合参数（2060 局，CL/CA = 1.00 基准）

- `a = 0.50`
- `lambda = 1.2`
- `R^2 = 0.91`

| 舰种 | K |
|---|---|
| CL/CA | 1.00 |
| DD | 0.83 |
| BB | 0.95 |
| CV | 0.43 |
| SS | 1.40 |

## 潜艇 1.75 验证

- 社区说法"潜艇效率额外乘 1.75"相对的是驱逐。
- 拟合 SS 相对 DD ≈ 1.68-1.70（新剧情 1.70，老剧情 1.70），接近 1.75。
- 视频的纯比例公式 `x = 1.75y/(1+0.75y)` 忽略均分地板，老剧情会高估。

## 方法论

1. 从 `interactions` 重建 per-target 伤害。
2. 除以 victim max_health 得到船等价效率。
3. 用网格搜索 a、lambda，并用局内 log-ratio 回归估计 K。
4. 拟合 R^2 约 0.91，跨 2060 局（新 317 / 老 1743）验证通过。

## 新老剧情差异

- CV 新剧情 0.385 低于老剧情 0.444。
- SS 新剧情 1.379 低于老剧情 1.415。
- 新剧情随机性更强，削弱潜艇背板能力：潜艇效率占比从老 12.6% 降到新 8.6%。

## 击杀数（frags）的独立贡献

在船等价效率（ship_eff）之外，击杀数是否还单独影响经验？局内去均值回归（n=14420 玩家行，含舰种哑变量）：

| 模型 | frags 系数 | R^2 |
|---|---|---|
| 只有 frags | +0.077 | 0.379 |
| eff + scouting | - | 0.618 |
| eff + scouting + frags | +0.012 | 0.622 |

- frags 单独看每击杀约 +8% 经验占比，但控制 eff 和 scouting 后降到 +1.2%，即补刀本身几乎没有独立奖励。
- 击杀的经验价值已经包含在 `ship_eff`（吃船比例）里。
- 池子层面 `team_frags` 系数 -0.0013，R^2 从 0.9687 到 0.9688，几乎无变化：总池子不受击杀总数影响。

脚本：`scripts/analyze_frags.py`，结果 `output/frags_analysis.json`。

## 击杀对象的等级（victim tier）

把吃船效率按被击沉船的等级拆成 4-5 / 6-7 / 8-9 / 10-11 四档，局内去均值回归
（n=14420，含舰种哑变量），每 1 个“船等价”带来的经验份额：

| 被击沉船等级 | 份额系数 |
|---|---|
| 4-5 | 0.0100 |
| 6-7 | 0.0149 |
| 8-9 | 0.0124 |
| 10-11 | 0.0145 |

四档系数都在 0.010-0.015 之间，且不随等级单调递增，说明**每“船等价”的经验收益与被击沉船的等级基本无关**。满血击杀一条 11 级战列和一条 9 级战列，都算 1 个船等价，收益没有明显区别。

注意这里的口径：收益按“吃船比例”（伤害 / 目标最大血量）计，而不是裸伤害。11 级船血量更多，要满血击杀它需要打更多裸伤害，但折算成船等价后仍是 1，不会额外多给经验。脚本：`scripts/analyze_victim_tier.py`。
