# 经验分配机制 + 舰种效率系数（机制 / 开发者版）

## 模型

对一局 n 名玩家：

```
contribution_i = ship_eff_i + lambda * (scouting_damage_i / 100000)

XP_share_i = a / n + (1 - a) * K[class_i] * contribution_i
                         / sum_j (K[class_j] * contribution_j)
```

- `ship_eff_i`：船等价击杀数 = 对每艘敌舰累加（你对它造成的伤害 / 它的最大血量）。
- `a`：均分地板比例（"任务池取平均"）。
- `lambda`：点亮伤害权重（每 10 万点亮伤害折算多少船等价）。
- `K[class]`：舰种效率系数。

## 拟合参数（2060 局，CL/CA = 1.00 基准）

- `a = 0.50`
- `lambda = 1.2`
- `R^2 = 0.91`

| 舰种 | K |
|---|---|
| CL/CA | 1.00 |
| DD | 0.83 |
| BB | 0.95 |
| CV | 0.43 |
| SS | 1.40 |

## 潜艇 1.75 验证

- 社区说法"潜艇效率额外乘 1.75"相对的是驱逐。
- 拟合 SS 相对 DD ≈ 1.68-1.70（新剧情 1.70，老剧情 1.70），接近 1.75。
- 视频的纯比例公式 `x = 1.75y/(1+0.75y)` 忽略均分地板，老剧情会高估。

## 方法论

1. 从 `interactions` 重建 per-target 伤害。
2. 除以 victim max_health 得到船等价效率。
3. 用网格搜索 a、lambda，并用局内 log-ratio 回归估计 K。
4. 拟合 R^2 约 0.91，跨 2060 局（新 317 / 老 1743）验证通过。

## 新老剧情差异

- CV 新剧情 0.385 低于老剧情 0.444。
- SS 新剧情 1.379 低于老剧情 1.415。
- 新剧情随机性更强，削弱潜艇背板能力：潜艇效率占比从老 12.6% 降到新 8.6%。

## 击杀数（frags）的独立贡献

在船等价效率（ship_eff）之外，击杀数是否还单独影响经验？局内去均值回归（n=14420 玩家行，含舰种哑变量）：

| 模型 | frags 系数 | R^2 |
|---|---|---|
| 只有 frags | +0.077 | 0.379 |
| eff + scouting | - | 0.618 |
| eff + scouting + frags | +0.012 | 0.622 |

- frags 单独看每击杀约 +8% 经验占比，但控制 eff 和 scouting 后降到 +1.2%，即补刀本身几乎没有独立奖励。
- 击杀的经验价值已经包含在 `ship_eff`（吃船比例）里。
- 池子层面 `team_frags` 系数 -0.0013，R^2 从 0.9687 到 0.9688，几乎无变化：总池子不受击杀总数影响。

脚本：`scripts/analyze_frags.py`，结果 `output/frags_analysis.json`。

## 击杀对象的等级（victim tier）

把吃船效率按被击沉船的等级拆成 4-5 / 6-7 / 8-9 / 10-11 四档，局内去均值回归
（n=14420，含舰种哑变量），每 1 个“船等价”带来的经验份额：

| 被击沉船等级 | 份额系数 |
|---|---|
| 4-5 | 0.0100 |
| 6-7 | 0.0149 |
| 8-9 | 0.0124 |
| 10-11 | 0.0145 |

四档系数都在 0.010-0.015 之间，且不随等级单调递增，说明**每“船等价”的经验收益与被击沉船的等级基本无关**。满血击杀一条 11 级战列和一条 9 级战列，都算 1 个船等价，收益没有明显区别。

注意这里的口径：收益按“吃船比例”（伤害 / 目标最大血量）计，而不是裸伤害。11 级船血量更多，要满血击杀它需要打更多裸伤害，但折算成船等价后仍是 1，不会额外多给经验。脚本：`scripts/analyze_victim_tier.py`。

## 非战斗舰艇与陆上设施

把吃船效率按目标类型拆开，并单独提取 `buildingInteractions` 的建筑伤害/击毁，局内去均值回归（n=14420，含舰种哑变量）：

| 贡献项 | 单位 | 系数（份额 / 单位） |
|---|---|---|
| 普通舰船 eff_ship | 1 船等价 | 0.01313 |
| 非战斗舰 eff_noncombat（运输船/鱼雷艇等） | 1 船等价 | 0.00892 |
| 点亮 scouting | 10 万伤害 | 0.01525 |
| 建筑伤害 building_damage | 10 万伤害 | 0.00745 |
| 建筑击毁 building_kills | 1 个 | 0.00255 |

结论：

- **运输船/鱼雷艇等非战斗舰艇仍按“吃船比例”计**（它们也在 `playersPublicInfo` 里、有最大血量），但每个船等价只值普通舰船的约 68%（0.00892 / 0.01313）。所以社区“鱼雷艇价值等同一条 5 级驱逐”略有高估，实际约 2/3 条普通船的收益。
- **陆上设施**（机场/炮台等）不在船等价体系里：建筑伤害每 10 万才 +0.00745 份额（约点亮的一半），建筑击毁每个 +0.00255。两者都很小，符合“打设施基本不赚钱、只有击毁勋带有一点点”的说法，但严格说建筑伤害本身也有一丁点收益，不是只有击毁那一下。

脚本：`scripts/analyze_noncombat.py`。

## 战斗持续时间

持续时间是局级变量，无法在局内去均值的分配回归里识别，因此分两层看：

- **总池层面**：`log(team_raw)` 在目标项（场景 + 星级 + 输赢）之外加入 `log(duration)`，R² 只从 0.9576 升到 0.9577，弹性系数 -0.032。总池不随战斗时长增长，拖时间不会让池子变大。
- **个体层面**：加入场景固定效应的合并回归里，`log(duration)` 系数约 -0.133（同样效率下，打得更久的局个人份额略低），R² 仅从 0.5279 升到 0.5300。这是“大家都打得更久、总效率变大，个人占比被稀释”的次级效应，不是直接的时长奖励。
- **单地图内再看时长**：对 28 张样本≥20 的图分别做 `log(team_raw) ~ stars + win + log(duration)`，时长系数均值 -0.08、中位数 -0.025、按样本加权 +0.012，正负各半（19 负 / 9 正）。说明同一张图里时长也没有一致影响；个别大系数（如赫尔墨斯高级 +0.99、营救猛禽普通 -0.66）是因为时长与星级/胜负高度共线（赫尔墨斯护送时长标准差仅 0.2 分钟），不是真实机制。

脚本：`scripts/analyze_duration.py`（全局）、`scripts/analyze_duration_per_map.py`（单图），结果 `output/duration_analysis.json`、`output/duration_per_map_analysis.json`。

## 樱花绽放的刷新点机制

樱花绽放（USS_CL）有刷新点机制，敌人会持续刷新。把全队“吃肉量”和池子直接对照（292 局）：

- 全队船等价效率（team_eff，吃掉的船）与池子相关：整体 corr +0.466，满星胜局里 corr +0.729。
- 池子回归 `log(team_raw) ~ 星级 + 输赢 + 场景 + team_eff`：team_eff 系数 0.00595/船等价，R² 从 0.9631 升到 0.9742。
- 满星胜局里 team_eff 从 14 到 63 不等，按 ×1.006 每船等价，跨这个范围池子差约 +34%。

但“拖时间”不等于“多刷人”：duration 与 team_eff 相关只有 0.06（满星胜局 0.076），基本无关。刷新量由波次表/难度决定，而不是靠拖时长。所以：**多刷人多吃肉确实让池子更大（次级效应，约 ×1.006/船等价），但想靠拖时间多刷新不成立。**

脚本：`scripts/analyze_cherry_spawn.py`，结果 `output/cherry_spawn_analysis.json`。

杀人鲸（NavalBase）同样如此，最后一共五波增援：全队吃掉的船等价（team_eff）与池子相关 +0.527（满星胜局 +0.503），`log(team_raw)` 回归里 team_eff 系数 0.00738/船等价，R² 从 0.9504 升到 0.9694；满星胜局 team_eff 范围 19-36，跨该范围池子差约 +13%。但 team_frags（击杀数）系数 -0.002，基本不影响——**吃三波还是五波全吃完，影响的是“吃船比例”总量，而不是击杀数本身。**
