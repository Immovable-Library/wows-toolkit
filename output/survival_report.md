# 存活时长与经验收益（按地图/分房）

> 口径：基础经验（raw_exp，不含高账 1.65）。存活时长 = 公开结果第 22 列
> `life_time_sec`；幸存到结束的玩家该值等于对局时长，缺失/为 0 按存活到结束处理。

## 全局结论（局内去均值，隔离效率/点亮/舰种）

- 控制吃船效率 + 点亮 + 舰种后，存活比例从 0 到 1（早死 → 活到最后）约 +**178** 基础经验。
- 加入存活比例后 R² 从 0.8203 升到 0.8284，说明存活时长对经验有独立于伤害的正向贡献。

## 经验获取速率曲线（存活时长维度）

把伤害/点亮/舰种的影响去掉后，按存活比例 10% 分档看边际经验：

- 二次拟合系数 a = -398.6，曲线**上凸（凹向下）**：存活带来的经验主要在**前半场**累积，后半场边际收益快速下降。
- 边际速率从早期的约 +250（每 10% 存活）一路降到后期的约 +6~+35，说明**越到后期，存活时间的经验获取速率越低**。
