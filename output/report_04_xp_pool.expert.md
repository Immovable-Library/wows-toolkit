# 总经验池机制（机制 / 开发者版）

## 模型

```
team_raw ~ base[scenario] * (1.09 ^ stars) * (win ? 1 : 0.5)
```

- `team_raw`：全队基础经验之和（池子大小）。
- `base[scenario]`：地图专属基线。
- `stars`：星级（0-5），等于次要任务完成度的封顶评级。

## 拟合质量与系数

`log(team_raw)` 回归（场景固定效应 + 星级 + 胜负），n=2058：

- `R^2 = 0.9576`
- 星级：+0.0860 / 星（×1.090）
- 胜负：+0.8209（胜 ×2.27，败约半池）
- 队伍效率：+0.0031 / 船等价（×1.003，可忽略）
- 队伍伤害：~0
- 挂机/暴毙人数：-0.0283 / 人（×0.972，约 -3%）

## 影响池子的全部因素

1. **地图 / 场景**（主因素）：`base[scenario]`。
2. **难度 / 旗舰变体**：Flagships/Random 等变体基线显著更高。
3. **星级**（0-5）：每星 ×1.09。
4. **胜负**：胜 ×2.27 vs 败。
5. **队伍效率 / 伤害**：几乎无影响（×1.003 量级）。
6. **挂机 / 暴毙人数**：每名约 -3%。
7. **次要任务原始个数**：已被星级（0-5 封顶）覆盖，不单列。
